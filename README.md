# Arlington Service Requests

A cloud-based web app for exploring Arlington County service request data.

## Problem
Arlington County has over 220,000 service requests that can be difficult to browse.

## Solution
A simple website to search, filter, and view service requests.

## Architecture
- **Frontend:** React + TypeScript
- **Backend:** Azure Functions
- **Storage:** Azure Blob Storage
- **Hosting:** Azure Static Web Apps
- **CI/CD:** GitHub Actions

## Features
- Search requests
- Filter by status
- Pagination

## Future Improvements
- Data visualizations
- AI-powered queries
